Dice Quest

Roll the dice. Create an algorithm. Find the treasure!

Be the first robot to collect all three treasures to win!

Each turn, roll 5 virtual dice and arrange the resulting puzzle piece commands into an algorithm to guide Roversa toward a treasure on the map. You must use all 5 commands, but you can arrange them in any order.

Special puzzle pieces:

  • Wild! Use it as any arrow command.
  • Repeat the command immediately before it.

Watch out! If Roversa drives off the map, it returns to the start.
